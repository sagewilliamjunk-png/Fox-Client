Context
The user is building Kitsune Client, a fox-themed Lunar/Feather-style Minecraft client (Fabric 1.21.11, Java 21). The existing codebase has a working Phase 1-3 foundation: package renamed to dev.kitsune.client, 14 legacy FoxFeatures, empty Module/ModuleManager skeleton, ClickGUI visual shell, profile system (with full CRUD), server rule enforcement with jar-swapping, and fox-branded title screen.
Strategy: Code custom whenever feasible. Use existing mods (Sodium, Lithium, Xaero's) as permanent dependencies for complex systems. Do NOT attempt to replace Xaero's minimap or Sodium — the ROI is terrible.
Gray-zone modules (ASK before implementing): Reach display, Hitbox tweaks, Weather/Time changer, Anti AFK.
